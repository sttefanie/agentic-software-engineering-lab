## Experiment Planning

Experiments should:

1. Test exactly one or a tightly related set of hypotheses
2. Define baseline conditions and treatment clearly
3. Specify all controlled and independent variables
4. Define measurable outcomes before execution
5. Document limitations and threats to validity
6. Report results objectively without bias toward hypothesis confirmation
7. Avoid assuming hypothesis correctness based on positive results

## Reproducibility

All experiments should be designed to be reproducible. Document:

- Exact procedures and steps
- Tool versions and configurations
- Random seeds for deterministic results
- How to access or recreate input data
- How to validate results
