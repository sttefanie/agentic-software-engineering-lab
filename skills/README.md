# Skills

This directory will contain reusable capabilities that can be loaded and composed by agents and workflows.

## Purpose

**Skills** represent encapsulated, reusable capabilities that solve specific problems or provide specific functionality. Skills are designed to be:

- **Modular** — Can be used independently or composed
- **Reusable** — Applicable across multiple agents and workflows
- **Loadable** — Instantiated on-demand when needed
- **Documented** — Clear about what they do, how to use them, constraints
- **Testable** — Can be validated independently

## Organization

Skills will be organized by functional area or capability (e.g., "code-generation", "testing", "documentation", etc.).

## Skill Template

When skills are defined, they will include:

- **Name** — Clear, descriptive name
- **Description** — What the skill does
- **Inputs** — Required and optional inputs
- **Outputs** — Expected outputs
- **Dependencies** — Required skills or capabilities
- **Constraints** — Limitations or restrictions
- **Examples** — Example usage
- **Metrics** — How to evaluate skill performance
