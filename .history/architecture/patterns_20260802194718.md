# Padrões Arquiteturais e de Design

**Status: SYNCHRONIZED WITH ACCEPTED ADRs**

## Padrão arquitetural principal

### Hexagonal Architecture / Ports and Adapters

**Status:** ACCEPTED

**Fonte:** ADR-003

Este padrão organiza o laboratório em torno de fronteiras explícitas entre domínio, aplicação e adapters. Ele é usado para manter o domínio independente de frameworks, bancos de dados e tecnologias de infraestrutura, reforçando a rastreabilidade das decisões arquiteturais.

## Padrões adicionais sustentados

### Spec-Driven Development

**Status:** ACCEPTED

**Fonte:** ADR-007

Este fluxo orienta o desenvolvimento a partir de specification, com validação e revisão humana em pontos críticos.

### Semantic Context Routing

**Status:** EXPERIMENTAL / SUPPORTED AS VARIABLE

**Fonte:** ADR-008

O roteamento semântico é tratado como uma abordagem experimental para comparação de contexto, e não como um resultado comprovado de melhoria de qualidade, custo ou latência.

## Observações

- Não foram introduzidos novos padrões nesta recuperação.
- A documentação evita afirmar que a arquitetura hexagonal reduz custos, alucinação ou tokens, pois esses efeitos não foram comprovados.
