# Visão Geral da Arquitetura

**Status: SYNCHRONIZED WITH ACCEPTED ADRs**

## Contexto

O laboratório mantém uma abordagem experimental para engenharia de software assistida por IA, com decisões arquiteturais registradas em ADRs aceitos. Esta visão geral reflete o estado atual dessas decisões sem introduzir novas decisões.

## Decisões arquiteturais atualmente aceitas

- **Linguagem principal:** Python 3.12, conforme ADR-001.
- **Framework de API:** FastAPI, conforme ADR-002.
- **Banco de dados principal:** PostgreSQL, conforme ADR-004.
- **Framework de testes:** pytest, conforme ADR-005.
- **Estilo arquitetural:** Arquitetura Hexagonal / Ports and Adapters, conforme ADR-003.
- **Workflow de desenvolvimento:** Spec-Driven Development, conforme ADR-007.
- **Camada agêntica:** projeto orientado para neutralidade de fornecedor, conforme ADR-006.
- **Context Engineering:** roteamento semântico como variável experimental, conforme ADR-008.

## Papel desta documentação

Esta documentação operacionaliza o contexto arquitetural para o repositório, mantendo a correspondência com os ADRs aceitos e sem substituir as decisões registradas neles.

## Observações importantes

- A arquitetura hexagonal estabelece dependências direcionadas para dentro e fronteiras explícitas entre domínio, aplicação e adapters.
- O roteamento semântico é tratado como hipótese experimental e não como resultado comprovado.
- As decisões de produto e de especificação continuam pendentes de decisão humana quando necessário.
