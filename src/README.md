## Implementation Principles

When implementation begins, the following principles will guide development:

1. **Spec-Driven** — Implementation follows formal specifications created beforehand
2. **Hypothesis-Driven** — Code supports testing specific hypotheses
3. **Measurable** — Implementation produces metrics for evaluation
4. **Vendor-Neutral** — Avoid unnecessary vendor lock-in
5. **Well-Documented** — Clear documentation of what, why, and how
6. **Traceable** — Link to specifications, hypotheses, and decisions
7. **Testable** — Automated tests validate functionality
